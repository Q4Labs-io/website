How we work

Every idea goes through the same five steps and ends with a decision.

$ ./experiment --run

The loop

  1. Idea. A real problem someone has, written in one sentence.
  2. Prototype. The smallest build that can test it. Days, not months.
  3. Test. Real people use it. We watch, ask and read every session.
  4. Measure. Did it hit the number we set before we started?
  5. Decide. Double down, change course, or drop it.

$ cat .labrc

House rules

Small before polished. We ship the rough version first. Polish is earned by usage.

Every experiment has a number. The target is set before we start, so the result can't be argued with afterwards.

Behaviour over opinions. What people do beats what they say they'd do. Ours included.

Drop fast, keep notes. When we drop an experiment, we write down why before moving on.

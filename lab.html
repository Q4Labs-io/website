How the lab works.

We're three builders running small, honest experiments. Every idea follows the same loop, and every loop ends with a decision.

$ ./experiment --run

The loop.

  1. Idea

    A real problem someone has, written down in one sentence.

  2. Prototype

    The smallest build that can test it. Days, not months.

  3. Test

    Real people use it. We watch, ask and read every session.

  4. Measure

    Did it hit the number we set before we started?

  5. Decide

    Double down, change course, or drop it and start the next one.

$ cat .labrc

House rules.

rule_01

Small before polished

We ship the rough version first. Polish is earned by usage.

rule_02

Every experiment has a number

We set the target before we start, so the result can't be argued with afterwards.

rule_03

Real users over opinions

Including ours. What people do beats what they say they'd do.

rule_04

Drop fast, keep notes

A dropped experiment still teaches us something. We write it down and move on.
